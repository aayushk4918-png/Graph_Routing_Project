
# Graph Routing Project

A shortest-path routing project focused on implementing and comparing graph algorithms such as Dijkstra, Bellman-Ford, A*, and Johnson’s Algorithm.

## Goals

- Implement shortest-path algorithms
- Generate test graphs and grid maps
- Compare algorithm performance
- Measure runtime and nodes explored
- Analyze time and space complexity
- Visualize routing results

## Project Modules

- **Module A:** Johnson’s Algorithm
- **Module B:** A* Search
- **Module C:** Mathematical and complexity analysis
- **Module D:** Performance evaluation and benchmarking
